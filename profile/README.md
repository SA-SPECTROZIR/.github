## Как начать

1. Перейдите на официальный сайт и скачайте установочный файл или архив: [Spectrozir Download](https://spectrozir.com/download) :contentReference[oaicite:12]{index=12}  
2. Установите приложение и подключите SDR-приёмник (например, HackRF One, TinySA и др.) через USB.  
3. Запустите приложение → выберите устройство → нажмите «Подключить». :contentReference[oaicite:13]{index=13}  
4. Выберите диапазон частот (например, Wi-Fi 2.4 ГГц или LTE 2600 МГц) и нажмите «Старт сканирования».  
5. Настройте вид графика: уровень сигнала, водопад (waterfall), маски и фильтры.  
6. Анализируйте спектр: ищите пики, помехи, сохраните снимок или экспортируйте данные для отчёта.
